# Static images

All SVGs in this folder were created for this project and may be used freely.

- `items/`, `shops/`, `covers/`, `backgrounds/` are scanned by `npm run assets`
  (runs automatically before `dev` and `build`) and offered in the admin forms.
- File names: lowercase letters, digits, `-` and `_` only; `.svg .png .jpg .jpeg .webp .avif`.
- Background images are tiled (320 × 320 px recommended).
- Everything under `public/` is reachable by direct URL **without login** – never store
  confidential handouts, maps with secrets, etc. here.
- Only add images you have the rights to use. Do not copy official D&D artwork.
